GRAPHNOTE — запуск
==================
1. Розпакуйте архів у будь-яку папку (не запускайте з-під архіву).
2. macOS: двічі клацніть  start.command
   (якщо macOS блокує: правий клік -> Відкрити -> Відкрити)
   Windows: двічі клацніть  start.bat
   Потрібен Python 3.
3. Відкриється браузер із застосунком. У вікні терміналу буде адреса для iPad.

На iPad (комп'ютер і iPad в одній Wi-Fi): відкрийте в Safari адресу виду http://192.168.x.x:8080.
Нотатки зберігаються в браузері пристрою (IndexedDB) окремо для кожної адреси —
щоб перенести їх, використайте Налаштування -> Експорт .zip / Резервна копія JSON і Імпорт.

Офлайн-режим і «На початковий екран» на iPad потребують HTTPS (напр. GitHub Pages),
через http по локальній мережі вони не працюватимуть.
