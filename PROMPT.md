# Промпт: Rust/WASM нотатник у стилі Obsidian для iPad (Safari)

Ти — старший Rust/WASM та frontend-інженер. Створи з нуля застосунок **«Graphnote»** — локальний markdown-нотатник із графом знань, що працює в Safari на iPad як PWA. Працюй самостійно, крок за кроком, після кожного етапу запускай збірку й тести та коммить зі зрозумілим повідомленням.

## 1. Мета та обмеження

- Цільовий пристрій: **iPad, Safari 16.4+** (PWA через «Додати на початковий екран»). Усе має працювати **офлайн**, без бекенду й акаунтів.
- Дані користувача залишаються на пристрої. Жодної телеметрії, жодних зовнішніх запитів у рантаймі (шрифти, CDN, аналітика заборонені — усе локально).
- Головна цінність: нотатки як **граф зв'язків** + архітектура, готова до підключення ШІ (Claude) пізніше. ШІ у v1 **не інтегрується**, але шар під нього обов'язковий (розділ 6).
- Обов'язково враховуй особливості iOS Safari: сенсорне керування, екранна й зовнішня клавіатура, Safe Area, обмеження сховища (ITP, вивільнення даних), відсутність надійного File System Access API.

## 2. Архітектура та стек

Монорепозиторій:

```
/core        Rust-крейт (lib, cdylib) -> WASM через wasm-bindgen + wasm-pack
/web         TypeScript + Vite, UI, PWA (manifest, service worker)
/docs        ARCHITECTURE.md, AI_INTEGRATION.md
```

- **Rust-ядро (WASM)** містить усю доменну логіку, без залежності від DOM:
  - парсинг markdown (`pulldown-cmark`) з розширеннями: `[[wikilink]]`, `[[note|псевдонім]]`, `[[note#заголовок]]`, `#теги`, YAML front matter (`serde_yaml` або легкий власний парсер), чекбокси `- [ ]`;
  - модель даних: `Note`, `Link`, `Tag`, `Graph`;
  - індекс: прямі посилання, **backlinks**, невирішені посилання (unresolved), осиротілі нотатки;
  - **повнотекстовий пошук** (власний інвертований індекс із нормалізацією Unicode, підтримка української та англійської, префіксний пошук, ранжування за BM25-подібною метрикою);
  - **силова розкладка графа** (force-directed, Barnes–Hut або grid-оптимізація), яка рахується у WASM і віддає координати у `Float32Array`;
  - серіалізація всього сховища в/із JSON та експорт markdown.
- **UI на TypeScript** (без важких фреймворків; допустимо Preact або чистий TS + Web Components). Редактор: **CodeMirror 6** з markdown-режимом, підсвіткою `[[wikilinks]]` і `#тегів`, автодоповненням `[[` (підказки назв нотаток із WASM).
- Граф малюється на **Canvas 2D** (або WebGL, якщо потрібна продуктивність для 2000+ вузлів).
- Збірка: `wasm-pack build --target web`, Vite. Rust: stable, `wasm-opt -Oz`, `lto = true`, `opt-level = "s"`. Підтримка `wasm-bindgen-test`.
- Межа WASM↔JS: передавай мінімум даних, великі структури — через typed arrays; жодних частих дрібних викликів у циклі рендера.

## 3. Функціонал v1 (обов'язково)

1. **Нотатки**: створення, перейменування (з автоматичним оновленням `[[посилань]]` в інших нотатках), видалення (у «кошик» із відновленням), папки/шляхи у назвах (`Проєкти/Ідея`).
2. **Редактор markdown**: live-preview-режим (рендер заголовків, виділень, списків, чекбоксів, посилань прямо в рядку, як у Obsidian) та перемикач «Редагування / Перегляд». Автозбереження з debounce.
3. **Wikilinks та backlinks**: клік по `[[посиланню]]` відкриває нотатку (або створює, якщо немає); панель backlinks із контекстними фрагментами; секція «Згадки без посилань» (unlinked mentions).
4. **Теги**: `#тег` та `#батько/дитина`; панель тегів зі лічильниками; фільтр за тегом.
5. **Пошук**: швидкий (<50 мс на 5000 нотаток), палітра команд / quick switcher (`Cmd+O`, `Cmd+P` для зовнішньої клавіатури, велика кнопка пошуку для сенсорного режиму).
6. **Граф знань**: глобальний та локальний (глибина 1–3 від поточної нотатки); вузли = нотатки, ребра = посилання, колір за тегом/папкою, розмір за кількістю зв'язків; **pinch-to-zoom, pan, tap по вузлу = відкрити, long-press = підсвітити сусідів**; фільтри (теги, осиротілі, невирішені), повзунки сил розкладки. Анімація 60 fps на iPad.
7. **Щоденні нотатки**: кнопка «Сьогодні» створює `Daily/YYYY-MM-DD` за шаблоном; мінікалендар; шаблони нотаток (папка `Templates`).
8. **Імпорт/експорт**: імпорт набору `.md` і `.zip` (папка vault), експорт усього сховища в `.zip` із markdown-файлами (структура папок збережена, front matter не втрачається), кнопка «Поділитися» через Web Share API, повний JSON-бекап.
9. **Зберігання**: **IndexedDB** (бібліотека `idb` або власна обгортка), версіоноване сховище з міграціями. Викликай `navigator.storage.persist()` і показуй користувачу статус та оцінку використаного місця. Нагадування про бекап (експорт) кожні N днів.
10. **Налаштування**: тема (світла/темна/системна), розмір шрифту, моноширинний/пропорційний шрифт редактора, ширина рядка, вимкнення автовиправлення в редакторі (атрибути `autocorrect="off" autocapitalize="off" spellcheck="false"` керуються перемикачем), мова інтерфейсу (укр/англ).

## 4. Вимоги до iPad UX

- Адаптивна розкладка: у ландшафті — 3 панелі (файли | редактор | backlinks/граф), у портреті — висувні панелі (drawer) із жестами.
- Цілі дотику ≥ 44×44 pt, жодних hover-only дій; контекстні меню — через long-press.
- Використовуй `env(safe-area-inset-*)`, `viewport-fit=cover`, `100dvh`, `visualViewport` API, щоб екранна клавіатура не перекривала курсор.
- Над клавіатурою — **панель швидких дій** (`[[ ]]`, `#`, `-`, `[ ]`, відступ, скасувати/повторити).
- Підтримка зовнішньої клавіатури: Cmd+N, Cmd+O, Cmd+F, Cmd+B/I, Cmd+Enter тощо; список гарячих клавіш у налаштуваннях.
- Підтримка Apple Pencil не потрібна, але не ламай виділення тексту й скрол.
- Запобігай зуму при фокусі на поле вводу (шрифт ≥ 16px), вимкни bounce-ефекти там, де потрібно (`overscroll-behavior`).
- PWA: `manifest.webmanifest`, іконки (180×180 apple-touch-icon, 192, 512, maskable), `apple-mobile-web-app-capable`, splash не обов'язковий. Service Worker з precache усіх ассетів і WASM, стратегія оновлення «оновити при наступному запуску» зі сповіщенням про нову версію.

## 5. Структура даних (Rust)

Мінімально:

```rust
pub struct NoteId(pub u64);

pub struct Note {
    pub id: NoteId,
    pub path: String,          // "Проєкти/Ідея"
    pub title: String,
    pub body: String,          // сирий markdown
    pub front_matter: Option<serde_json::Value>,
    pub created_at: i64,
    pub updated_at: i64,
}

pub struct Link { pub from: NoteId, pub to: LinkTarget, pub alias: Option<String>, pub span: (usize, usize) }
pub enum LinkTarget { Resolved(NoteId), Unresolved(String) }

pub struct Vault { /* notes, link index, tag index, search index */ }
```

- Усі публічні методи WASM мають тип-безпечні TS-типи (`tsify` або `serde-wasm-bindgen`).
- Інкрементальне переіндексування: зміна однієї нотатки не перебудовує весь індекс.
- Детермінована поведінка: однакові дані → однакові результати (для тестів).

## 6. ШІ-готовий шар (без реальної інтеграції у v1)

Спроєктуй ядро так, щоб Claude можна було підключити, не переписуючи архітектуру:

- **Trait `KnowledgeProvider`** (Rust) та відповідний TS-інтерфейс із методами: `get_note(id)`, `search(query, limit)`, `neighbors(id, depth)`, `backlinks(id)`, `subgraph(ids, depth)`, `list_tags()`, `get_context_bundle(id, token_budget)`.
- **`get_context_bundle`** повертає структурований контекст для LLM: поточна нотатка + найближчі сусіди графа + backlinks, обрізаний за бюджетом токенів (приблизна оцінка за символами), у вигляді компактного JSON/markdown із ідентифікаторами нотаток для цитування.
- **Шар ембедингів (заглушка)**: trait `EmbeddingStore` (`upsert(id, vector)`, `nearest(vector, k)`), реалізація «в пам'яті» + збереження в IndexedDB, косинусна подібність у Rust. Чанкування нотаток за заголовками (`chunk_note`). Постачальник ембедингів — trait `EmbeddingProvider`, у v1 лише `NoopProvider`.
- **Подієвий журнал змін** (`ChangeLog`): події `NoteCreated/Updated/Renamed/Deleted/LinkAdded/LinkRemoved` — щоб ШІ-шар міг інкрементально оновлювати індекси.
- **Структура під «пропозиції ШІ»**: тип `Suggestion { kind: LinkSuggestion | TagSuggestion | Summary | NewNote, target: NoteId, payload, confidence }` і панель «Пропозиції» в UI (у v1 порожня/демонстраційна), де користувач приймає або відхиляє зміну; жодних автоматичних записів без підтвердження.
- Документ `docs/AI_INTEGRATION.md`: як підключити Claude API (ключ зберігається локально, запити лише на явну дію користувача), приклад tool-use схеми (`search_notes`, `get_note`, `get_neighbors`, `create_note`, `add_link`), політика приватності, оцінка вартості контексту.

## 7. Продуктивність і якість

- Холодний старт < 2 с на iPad (WASM ≤ 1 МБ gzip-розміру ядра, lazy-завантаження графа).
- 5000 нотаток × 2 КБ: пошук < 50 мс, відкриття нотатки < 100 мс, граф 1000 вузлів ≥ 30 fps.
- Тести: unit-тести Rust (парсер wikilinks з крайніми випадками: вкладені дужки, код-блоки, екранування, юнікод/кирилиця; backlinks; перейменування; пошук; розкладка графа), `wasm-bindgen-test`, мінімум Playwright e2e (створити нотатку → зв'язати → побачити в графі → експорт). Playwright з емуляцією iPad (WebKit).
- CI (GitHub Actions): `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`, `wasm-pack test --headless`, `npm run build`, `playwright test`; деплой на GitHub Pages з коректним `base` та `scope` service worker.
- Доступність: семантична розмітка, ARIA-ролі, контраст AA, підтримка Dynamic Type там, де можливо.

## 8. План робіт (виконуй по етапах, після кожного — коміт і короткий звіт)

1. Каркас монорепо, збірка Rust→WASM, «hello» у Vite, PWA-скелет, CI.
2. Ядро: модель даних, парсер markdown/wikilinks/тегів, індекс посилань і backlinks + тести.
3. Сховище IndexedDB, CRUD нотаток, перейменування з оновленням посилань.
4. UI: редактор CodeMirror, список файлів, backlinks-панель, адаптивна розкладка під iPad.
5. Пошук і quick switcher.
6. Граф (розкладка в WASM, Canvas, жести), фільтри, локальний граф.
7. Теги, щоденні нотатки, шаблони.
8. Імпорт/експорт (.md, .zip, JSON), нагадування про бекап, persist storage.
9. ШІ-готовий шар (traits, context bundle, ембединги-заглушка, ChangeLog, панель пропозицій) + `docs/`.
10. Полірування: продуктивність, доступність, іконки, фінальні e2e, README з інструкцією «як встановити на iPad».

## 9. Правила роботи

- Якщо вимога неоднозначна — обирай просте рішення, зазнач припущення в `docs/ARCHITECTURE.md` і йди далі; не зупиняйся для уточнень без крайньої потреби.
- Не додавай залежностей без потреби; для кожної важкої залежності вказуй причину та вплив на розмір бандла.
- Не вигадуй API, яких не існує; перевіряй, що Safari/iOS підтримує використані веб-API, і додавай fallback.
- Пиши чистий, прокоментований де потрібно код; уникай `unsafe` у Rust без обґрунтування.
- У фінальному звіті: що зроблено, що не зроблено, відомі обмеження iOS Safari, як запустити локально (`npm run dev`, `npm run build`, `cargo test`) та як відкрити на iPad (HTTPS-хост або GitHub Pages → «Поділитися» → «На початковий екран»).

## Критерії готовності v1

- Застосунок встановлюється на iPad як PWA й працює в літаковому режимі.
- Можна створювати нотатки з `[[посиланнями]]`, бачити backlinks, теги, пошук і інтерактивний граф із жестами.
- Дані переживають перезапуск, а повний експорт/імпорт відновлює vault без втрат.
- Усі тести та CI зелені; є `docs/AI_INTEGRATION.md` і працюючий `KnowledgeProvider` з `get_context_bundle`.
